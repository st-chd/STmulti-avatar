# STmulti-avatar (멀티 아바타)

캐릭터와 페르소나에 여러 이미지를 등록하고, 목록과 채팅방에서 각각 다른 이미지를 표시하는 실리태번 확장입니다.

## 기능

- 캐릭터창 아바타 아래 "추가 이미지" 접이식 섹션의 필름스트립에서 이미지를 추가/삭제
- 이미지가 많을 때 접어둘 수 있고, 접이식 섹션에 숫자를 표기하여 총 몇 개의 이미지가 추가되었는지 확인
- 페르소나창의 `Global Settings` 바로 아래에도 같은 "추가 이미지" 섹션 제공
- 추가 이미지와 채팅 선택창의 썸네일은 기본 프로필 크기 및 현재 테마의 원/정사각형/rounded/직사각형 설정을 따름
- 이미지 중 하나를 캐릭터 목록용 대표 이미지로 지정 (캐릭터창의 큰 아바타에도 동일하게 반영)
- 채팅 메시지의 <i class="fa-solid fa-images"></i> 버튼으로 그 채팅방에서만 다른 이미지로 전환 (원본으로 강제 복귀도 가능)
- 채팅 선택창의 "원본"에도 실제 원본 썸네일 표시
- 사용자 메시지는 페르소나, AI 메시지는 캐릭터로 구분하며, 이전 메시지에 고정된 페르소나도 해당 이미지 설정을 사용
- 업로드 시 기본 아바타와 동일한 2:3 크롭 지원. 사용자 설정의 **아바타 크기 변경하지 않음**을 체크하면 크롭 창 없이 원본 가로·세로 크기를 유지한 PNG로 저장
- 캐릭터 삭제/복제/이름 변경 시 이미지와 설정을 자동으로 정리

## 표시 우선순위

- 캐릭터 목록: 대표 이미지 → 원본
- 채팅방: 방별 설정 → 대표 이미지 → 원본

## 사용법

1. 캐릭터창을 열고 "추가 이미지" 섹션을 펼친 뒤 `+` 버튼으로 이미지를 추가합니다.
2. 목록에 쓸 이미지를 클릭해 대표 이미지로 지정합니다. (맨 앞 "원본" 타일을 클릭하면 대표 이미지 해제)
3. 채팅방에서는 메시지의 이미지 버튼을 눌러 이 방에서만 쓸 이미지를 고릅니다.
4. 페르소나는 해당 페르소나를 선택한 다음 `Global Settings` 아래에서 같은 방법으로 관리합니다. 이름이 같은 캐릭터와도 설정이 분리됩니다.
5. 데스크톱에서는 이미지 위에 마우스를 올려 `×`로 삭제하고, 터치 기기 또는 좁은 화면에서는 길게 눌러 삭제합니다.

## 이미지 저장 위치

`data/<유저>/user/images/<이미지 폴더>/` 아래에 PNG로 저장됩니다.

- 새 캐릭터 라이브러리: `이름_avatar/`
- 새 페르소나 라이브러리: `persona_아바타파일명_avatar/` (원본 파일의 확장자는 제외)

## 이미지 정리

확장 설정(`Multi Avatar` 패널)에서 정리 범위를 선택할 수 있습니다.

- **모든 데이터 정리**: 캐릭터와 페르소나의 추가 이미지 및 관련 설정을 모두 제거합니다.
- **페르소나 이미지 정리**: 모든 페르소나의 추가 이미지와 관련 설정만 제거합니다. 캐릭터의 추가 이미지와 설정은 유지됩니다.
- **캐릭터 이미지 정리**: 모든 캐릭터의 추가 이미지와 관련 설정만 제거합니다. 페르소나의 추가 이미지와 설정은 유지됩니다.

원본 프로필 사진, 캐릭터·페르소나 자체, 채팅 메시지는 삭제하지 않습니다. 일반 채팅과 그룹 채팅에 저장된 이미지 선택 정보도 선택한 종류만 정리합니다. 각 버튼은 삭제 전에 대상과 이미지 개수를 표시하며, 취소하면 정리하지 않습니다.

## 확장 삭제 전

확장 설정(`Multi Avatar` 패널)의 **모든 데이터 정리** 버튼을 눌러 이미지 파일, 카드 설정, 모든 채팅 기록의 관련 데이터를 완전히 삭제한 뒤 확장을 삭제하세요.

페르소나의 추가 이미지와 확장 설정도 함께 정리합니다.
