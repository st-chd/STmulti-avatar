# STmulti-avatar (멀티 아바타)

캐릭터 하나에 여러 이미지를 등록하고, 캐릭터 목록과 채팅방에서 각각 다른 이미지를 표시하는 실리태번 확장입니다.

## 기능

- 캐릭터창 아바타 아래 "추가 이미지" 접이식 섹션의 필름스트립에서 이미지를 추가/삭제 (이미지가 많아도 접어두면 깔끔함, 개수 표시)
- 이미지 중 하나를 캐릭터 목록용 대표 이미지로 지정 (캐릭터창의 큰 아바타에도 동일하게 반영)
- 채팅 메시지의 <i class="fa-solid fa-images"></i> 버튼으로 그 채팅방에서만 다른 이미지로 전환 (원본으로 강제 복귀도 가능)
- 업로드 시 기본 아바타와 동일한 2:3 크롭 지원
- 캐릭터 삭제/복제/이름 변경 시 이미지와 설정을 자동으로 정리

## 표시 우선순위

- 캐릭터 목록: 대표 이미지 → 원본
- 채팅방: 방별 설정 → 대표 이미지 → 원본

## 사용법

1. 캐릭터창을 열고 "추가 이미지" 섹션을 펼친 뒤 `+` 버튼으로 이미지를 추가합니다.
2. 목록에 쓸 이미지를 클릭해 대표 이미지로 지정합니다. (맨 앞 "원본" 타일을 클릭하면 대표 이미지 해제)
3. 채팅방에서는 메시지의 이미지 버튼을 눌러 이 방에서만 쓸 이미지를 고릅니다.

## 이미지 저장 위치

`data/<유저>/user/images/<캐릭터 폴더>/` 아래에 PNG로 저장됩니다. 폴더명은 첫 업로드 시의 캐릭터 아바타 파일명으로 고정되며, 이후 캐릭터 이름이 바뀌어도 유지됩니다.

## 확장 삭제 전

확장 설정(`Multi Avatar` 패널)의 **모든 데이터 정리** 버튼을 눌러 이미지 파일, 카드 설정, 모든 채팅 기록의 관련 데이터를 완전히 삭제한 뒤 확장을 삭제하세요.
